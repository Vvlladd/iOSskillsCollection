## What came from upstream

The active-discipline framing, `CONTEXT.md` as a glossary and nothing else, the file layout, the session behaviors (challenge, sharpen, stress-test, cross-reference, update inline), and the three-part test for when a decision earns an ADR.

## What was added here

Making illegal states unrepresentable with enums; domain types over primitive obsession via `RawRepresentable`; Swift API design naming; per-module contexts for SPM/Tuist; and the Apple-platform decisions that typically warrant an ADR.
